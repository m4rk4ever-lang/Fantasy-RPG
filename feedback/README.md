# Feedback

Deze map is voor feedback van de eigenaar, naast issues met het label `feedback`.

## Zo werkt het

- Zet een nieuw bestand in deze map, bijvoorbeeld `2026-11-20-camera.md`. Eén onderwerp per bestand werkt het best.
- Screenshots of schetsen mogen erbij (zelfde naam, `.png` of `.jpg`).
- De bouwagent leest elke run alle bestanden in deze map (behalve deze README), verwerkt ze vóór nieuw roadmapwerk en verplaatst verwerkte bestanden naar `feedback/verwerkt/`, met onderaan een korte notitie wat er gedaan is.
- Is iets nog niet (helemaal) gedaan, dan blijft het bestand staan en staat in de changelog wanneer het opgepakt wordt.

Alleen bestanden die de eigenaar zelf in de repo zet worden als opdracht gezien.

## Voorbeeld

```markdown
# Camera te dichtbij

Bij sprinten zit de camera te dicht op de held. Graag iets verder weg, vooral in het open veld.
```
