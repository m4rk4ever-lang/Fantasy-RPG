## Assets
Alle modellen, shaders en het terrein zijn procedureel in code gemaakt voor dit project. Er zijn nog geen externe assets gebruikt.

## 3D-modellen (13-11-2026)

- **Quaternius** (https://quaternius.com), CC0 1.0: `adventurer.glb`, `hooded_adventurer.glb` (held en dorpelingen), `zombie.glb` (basis voor de Hollowed), `sword.glb`. Verkregen via het npm-pakket `@netforge/asset-library-files` 0.2.0, waarvan de `NOTICE` per model de CC0-status vermeldt en het `CC0-1.0.txt` meelevert. Meshopt-compressie verwijderd met gltf-transform. Kleuren aangepast aan `docs/SMAAK.md`; de Hollowed krijgen een eigen asgrijze shader en Veil-ogen; de held draagt eigen uitrusting (schouderstukken, borstplaat, cape) die in code is gebouwd.
